Problem & logic

Model installment purchases with down payments and upfront fees, while distributing rounding remainders in integer cents.

Implementation

Separate financial functions from the interface, validate inputs, and display translated results in Spanish and English.

Testing & delivery

Automated calculation and translation checks, browser testing, and a CI workflow that builds and deploys through GitHub Actions.
